# one-liner
Python One-Liner Challenges

An interactive web platform for learning and practicing Python one-liners! Solve coding challenges with single-line solutions and improve your Python skills.

## Features

- 🎯 **10 Progressive Challenges** - From easy to hard difficulty levels
- 💻 **Split-Screen Interface** - Challenge description on the left, code editor on the right
- ✅ **Automated Testing** - Each challenge has test cases to validate your solution
- 🎨 **Modern Dark UI** - Clean, professional interface inspired by VS Code
- 📊 **Progress Tracking** - Keep track of completed challenges
- ⌨️ **Keyboard Shortcuts** - Ctrl/Cmd + Enter to run code

## Installation

1. Clone the repository:
```bash
git clone https://github.com/BernieCodez/one-liner.git
cd one-liner
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to:
```
http://localhost:5000
```

## How to Play

1. Read the challenge description on the left panel
2. Write your Python one-liner solution in the editor
3. Click "Run Code" or press Ctrl/Cmd + Enter
4. View test results in the console below
5. Once all tests pass, move to the next challenge!
